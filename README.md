# 🌌 CosmoAI - Explorando o Universo com IA

> 🚧 **Projeto em Desenvolvimento** 🚧

O **CosmoAI** é uma plataforma web moderna focada na divulgação científica e exploração astronômica, destacando como a Inteligência Artificial está transformando nossa compreensão sobre o cosmos, galáxias, nebulosas e o Sistema Solar.

## 🚀 Funcionalidades (Em Desenvolvimento)

- **Página Hero:** Introdução interativa ao uso de IA na astronomia.
- **Seção "Conheça CosmoAI":** Detalhes sobre a missão da plataforma e artigos explicativos.
- **Categorias Astronômicas:**
  - 🌌 **Nebulosas:** Exploração dos diferentes tipos (Emissão, Reflexão, Escuras, Planetárias).
  - 🪐 **Sistema Solar:** Dados e imagens detalhadas dos corpos celestes da nossa vizinhança.
  - ⭐ **Estrelas:** Classificação e evolução estelar monitoradas por IA.

---

## 🛠️ Tecnologias Utilizadas

- **Frontend:** HTML5, CSS3, JavaScript
- **Design/UI:** Tema escuro (Dark Mode) responsivo focado na experiência do usuário
